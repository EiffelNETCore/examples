# Building NET Core MVC web application using Eiffel


This guide will help you build Web APIs using .NET and Eiffel, providing data to different clients through a uniform contract.


## Prerequisites
- .NET 7
- EiffelStudio 23.09 or greater

## Web Technologies
- HTTP
- ASP.NET Core 7, 6

### Compiling the Eiffel Project
Open the project and compile it in one of the following mode. 
  * Workbench
  * Finalized

#### Note 

        If you got an compilation error when you are working with Eiffel and .NetCore try first to 
        * compile from scratch (Delete the EIFGENs)
        * clean the folder `Eiffel User Files` usually under the User Documents folders,


## Run Application
Use the `run_app.bat` script to launch the application

```cmd
$ run_app.bat w  -- will launch the app in Worbench mode
```

```cmd
$ run_app.bat f  -- will launch the app in Finalized mode
```
